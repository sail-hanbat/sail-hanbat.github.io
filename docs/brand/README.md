# SAIL brand assets

Each layout is provided in three formats:

- `*-transparent.png`: high-resolution PNG with a transparent background
- `*-white.jpg`: high-resolution JPEG with a white background
- `*.svg`: editable vector master

Layouts:

1. Icon only
2. Icon with `SAIL`
3. Icon with `SAIL` and the full lab name on one line
4. Icon with `SAIL` and the full lab name on two lines

The two-line lockup is the primary version. Its spacing and alignment follow the
wordmark used in the website header; the other layouts are supporting variants.

Brand colors:

- Oxblood red: `#891515`
- Charcoal gray: `#555555`
